# Ponto Nómada design system

Direction A, **Caderno de Viagem** (DECISIONS D20, chosen by Miguel), written down as the contract
for the Instagram slides now and the website (M3, Astro + Tailwind) later. The slides already use it.

- **Source of truth for values:** `src/escapadinha/renderer/tokens.py`. The base palette is
  `design_directions/directions.py` (`CADERNO`). The module adds state colours, photo rules, type
  scales, spacing, radii and shadows.
- **Machine-readable tokens:** [`tokens.json`](tokens.json), generated by
  `uv run python -c "from escapadinha.renderer import tokens; tokens.write_json()"`. Never edit it
  by hand. `tests/test_design_system.py` fails when the JSON is stale or when any text pair drops
  below its WCAG minimum.
- **Slide implementation:** `renderer/templates/base.html.j2` (tokens, CSS components) and
  `_ui.html.j2` (masthead, price block, dots, credit, photo layer).

The spirit: a printed travel notebook. Paper, ink and one terracotta rust; large, captioned
photographs; serif type with personality; thin rules, never boxes with heavy borders. Every price
is presented as a verified fact: what, when a traveller found it, when we checked it.

## 1. Type

Two families, both SIL Open Font License 1.1, self-hosted (D21):

| Role | Family | Used for |
|---|---|---|
| `display` | **Fraunces** (variable: `opsz` 9–144, `wght` 100–900, roman + italic) | Headlines, prices, numerals, the wordmark |
| `text` | **Source Serif 4** (variable: `opsz` 8–60, `wght` 200–900, roman + italic) | Body, data, labels, captions |

Fallback stacks: `Fraunces, "Iowan Old Style", Georgia, serif` and
`"Source Serif 4", Georgia, "Times New Roman", serif`.

- Files: `assets/fonts/*.woff2` (Latin subset with Latin Extended-A/B, general punctuation, €,
  arrows and math minus; all OpenType features; Fraunces pinned to `SOFT 0`, `WONK 0`) plus
  `OFL-Fraunces.txt` and `OFL-SourceSerif4.txt`. Neither font declares a Reserved Font Name, so
  subsetting and WOFF2 conversion are allowed under the OFL.
- `font-optical-sizing: auto` everywhere. Fraunces at display sizes uses its high-contrast optical
  size; at small sizes it opens up automatically.
- **Numbers:** prices and dates use `lining-nums tabular-nums`, so digits line up and never jump.
  Old-style numerals are only for decorative numbers in running text.
- Italic Fraunces is the "voice" of the brand: the wordmark, the CTA ("*Link na bio*"), tip
  numerals and section headings in long reads. Do not set body copy in italic.
- Labels (`label`) are Source Serif 4 600, uppercase, letter-spacing 0.14em. Use them for kickers
  ("FICHA DA VIAGEM"), table keys and stamps. Never for sentences.

## 2. Colour

Tokens are CSS variables `--pn-<name>`; Tailwind classes point at them (`colors.bg = var(--pn-bg)`),
so one class works in both modes. `:root` carries light; `prefers-color-scheme: dark` (and a
`data-theme="dark"` override) carries dark.

| Token | Light | Dark | Use |
|---|---|---|---|
| `bg` | `#F5F0E6` paper | `#16140F` | Page background |
| `surface` | `#FFFDF8` | `#201D17` | Cards, the ficha, tables |
| `ink` | `#1E1B16` | `#EEE7D8` | Text, double rules |
| `muted` | `#5F574B` | `#B3A994` | Meta, captions, keys |
| `accent` | `#A23E1C` terracotta | `#F0936B` | Links, labels, the route arrow, the button |
| `on-accent` | `#FFFFFF` | `#16140F` | Text on accent (button, stamp) |
| `rule` | `#D3C8B4` | `#3D372C` | Hairlines and row separators (decorative) |
| `success` / `success-bg` | `#2F6830` / `#E4EEDC` | `#93C98C` / `#1D2A1B` | "−32% abaixo do habitual", live promotion |
| `warning` / `warning-bg` | `#835400` / `#F6EACB` | `#E3B65C` / `#2D2514` | Remote airport ("longe do centro"), warming-up typical low, "confirma antes de pagar" |
| `expired` / `expired-bg` | `#8F1D33` / `#F7E1DF` | `#F4A3AE` / `#331A1D` | Expired promotion stamp and notice |

Photo tokens: text on photographs is `photo.ink` `#FFFDF8` on a warm-ink scrim `photo.scrim`
`#16140F` at **≥ 0.70** opacity wherever text sits (`photo.scrimTextAlpha`).

Rules:
- The accent is a colour of emphasis, not a background for areas. One accent element per view
  (arrow, label, button), plus the stamp on photos.
- **State is never colour alone:** every success/warning/expired colour comes with words
  ("abaixo do habitual", "longe do centro", "Expirada"). Expired red (`#8F1D33`) is crimson, the
  accent is orange-rust; they must not appear side by side as the only distinction.
- On photos, never use the accent as a text colour (`#F0936B` over a scrim is 2.9:1). Use it as a
  solid stamp with `on-accent` text.
- `rule` is decorative (row separators). Anything a user must see (input borders, focus) uses
  `ink` or `accent`.

## 3. Space, radii, shadows

Spacing (`spacing`, 4 px base): `2xs` 4 · `xs` 8 · `sm` 12 · `md` 16 · `lg` 24 · `xl` 32 ·
`2xl` 48 · `3xl` 64 · `4xl` 96 px. Page side gutter on phones: 16 px; content measure 60–70ch;
max page width 1120 px. Slides: gutter 72 px, card padding 52 px, stack gap 28 px.

Radii (`borderRadius`): editorial means square. `none` for photos, cards and buttons; `sm` 2 px for
tags; `md` 4 px for inputs; `full` only for progress dots.

Shadows (`boxShadow`): paper does not float. `card` (a hairline plus a soft drop) only for cards
over a busy background; `lifted` for the paper card over a photo on slides; `focus` is a 3 px accent
ring for keyboard focus. Flat surfaces separated by rules are the default.

## 4. Components

Each component lists the slide class (implemented) and the web intent (M3).

### Masthead and nav
Logo left, one label or stamp right, a **double rule** (`7px double ink` on slides, `3px double` on
the web) underneath on paper. On photos the masthead sits on the top scrim and uses the dark logo.
Web nav: the masthead plus up to five links in `label` style (Promoções · Rotas · Roteiros · Dicas ·
Sobre), current page in `ink` with an accent underline; on phones a single "Menu" button.

### Price block (fast scan) — `ui.price_block`
The answer to D20's weakness: price, dates and when it was found are **always together, in this
order, in the same component**, on cards, slides and pages.

```
Lisboa → Paris (Beauvais)          ← route (headline; remote airport named here)
91€                    [−41%]      ← price (price-xl, ink, lining tabular) + success tag
                abaixo do habitual
           ida e volta, por pessoa
qua, 9 dez → sex, 11 dez · 2 noites ← dates (body 600), nights muted
Encontrado por um viajante a 12/10/2026   ← found_date (small, muted, date in ink 600)
```

- The price is the biggest thing on the surface, in `ink` (not accent: maximum contrast). The
  currency sign is 0.4em and raised, so the number reads first.
- The discount is a `success` tag with a number and words; no tag when there is no typical low
  (rule `price_cap`: no "% below" claim).
- "Encontrado a" is the traveller's `found_date`. "Verificado a" (our `fetched_at`, Lisbon time)
  goes in the ficha and on the promotion page, always labelled as ours. Never merge the two.
- Expired: the price is struck through in `muted`, the success tag is replaced by an `expired` stamp,
  and there is no button.

### Card
`surface` panel, `7px double ink` top rule, padding 52 px on slides / `lg`–`xl` on the web. Over a
photo it gets the `lifted` shadow; on paper it has no shadow and is separated by rules. Promotion
card (web): photo 3:2 with caption, route `title`, price block (`price` size), arrival airport line.

### Tag and stamp
- **Tag** (`.tag.success|warning|expired`): tint background, state colour text, radius `sm`,
  `small` size, sentence case: "−32%", "longe do centro".
- **Stamp** (`.stamp`): `label` type in a 3 px accent border, or `.stamp.solid` (accent background,
  `on-accent` text) on photos: "PROMOÇÃO", "RESERVA JÁ", "EXPIRADA" (expired colour).

### Button
One primary style: accent background, `on-accent` text, Source Serif 4 600, letter-spacing 0.04em,
square corners, padding 14 × 22 px, min height 44 px. Hover darkens via an underline, not a colour
shift; focus uses the `focus` ring. Copy is a verb: "Ver voo e reservar". Affiliate links carry
`rel="sponsored nofollow"`. **Never on an expired promotion.** Secondary action: a text link in
accent with a 1 px underline.

### Notice — `.notice`
A rule on the left (6 px) and text in `small`:
- **Disclosure** (neutral, `rule` border): the exact `presentation.DISCLOSURE` text. On every deal
  CTA slide, every deal caption, every page with an affiliate link.
- **Expired** (`.notice.expired`, expired border and tint): "**Expirada.** Esta promoção já
  expirou: o preço subiu. Fica aqui como registo, sem ligação de reserva."
- **Warning** (warning border and tint): "Chegada a Beauvais (BVA), longe do centro de Paris. Conta
  com o transfer no tempo e no orçamento."

### Table and ficha rows — `.rows`
Key in `label` (muted), value in `body` 600 right-aligned, `2px rule` between rows, `2px ink` rule on
top. Numbers right-aligned and tabular. Web tables (typical low per month) use the same rows; the
month column left, the price column `price`-styled at `title` size, data count in `muted`.

### Footer
A double rule, then in `small` muted: where the numbers come from ("preços encontrados por
viajantes no Aviasales e guardados por nós; não são preços ao vivo"), "Horas de Lisboa", the build
time, the disclosure in italic, links to Sobre and Privacidade. Slides end with a footer row: photo
credit or guide title on the left, progress dots on the right.

## 5. Photo treatment

- **Large and captioned.** Photos are full-bleed on covers and wide bands on pages, always with a
  caption that names the place and credits the author: "Paris · Foto: MARTINOPHUC / Pixabay"
  (`caption` style). Pixabay does not require credit; we give it anyway (D5).
- **Text on photos only on a scrim.** The scrim is warm ink `#16140F`, eased (many stops, no visible
  band) and at least 0.70 opaque under any text. Measured worst case: 6.69:1 over pure white.
  - Top scrim (`.scrim-top`): 0.82 → 0.72 at 160 px, eased to 0 at 330 px. Only the masthead sits
    there.
  - Bottom scrim (`.scrim-bottom`): eased from 0 to 0.76 over 140 px; the caption row starts at 150 px.
  - Fade-to-page (`.fade-top`, CTA slides): the photo occupies the top 700 px and fades into `bg`;
    text starts below the fade.
- **Anything to read sits on paper.** Price, route, dates and found date are on the paper card,
  never directly on the photo, so a busy photo cannot hurt them. Checked over every cached photo
  (Amsterdam façades, Berlin's white columns, Milan, Rome, London, Barcelona).
- No filters, no duotones, no rounded photo corners. A gentle `saturate(.85)` is allowed on small
  thumbnails on the web.
- No photo: a dark warm gradient (`#3D372C → #16140F`), never a stock placeholder.

## 6. Logo (provisional)

`assets/logo-light.svg` (ink, for paper) and `assets/logo-dark.svg` (paper colour, for photos and
dark mode). It has a line mountain with a terracotta sun and the wordmark "Ponto Nómada" in Fraunces
Italic 500 at opsz 144, **outlined to paths**, so it renders the same without the font. Height ≥ 40 px
on screens, 58 px on slides; clear space = the sun's diameter all round. The designer's logo (M6)
replaces both files with the same names.

## 7. Tone of voice (pt-PT)

Literary but precise: a travel notebook written by someone who checks facts. "Tu", warm and short,
never shouting. No exclamation marks in headlines, no "IMPERDÍVEL", no emojis on slides (captions may
use a few as bullets).

- **Never invent a price.** Every number comes from a stored observation. Say who found it and when:
  "Um viajante encontrou este preço a 12/10/2026", "Verificado por nós a 12/10/2026 às 22:00 (hora
  de Lisboa)". Prices are found, not live: "pode já ter mudado".
- **Name the arrival airport,** and the remote one in the headline: "Lisboa → Paris (Beauvais)".
- **Dates:** "qua, 9 dez → sex, 11 dez · 2 noites" on slides; "9 a 11 de dezembro" in prose; numbers
  pt-PT ("49,50 €", "−41%"). All formatting comes from `i18n_pt.py`; times in Europe/Lisbon.
- **Comparisons are honest:** "41% abaixo do habitual" means the route's typical low for that
  departure month (glossary: *preço habitual*), never "the average fare".
- **Disclosure always**, word for word: "Publicidade · Este post contém links de afiliado: se
  reservares através deles, podemos receber uma comissão, sem custo extra para ti."
- **Expired is said plainly:** "Expirada: o preço subiu. Fica como registo, sem ligação de reserva."

Examples:

| Instead of | Write |
|---|---|
| "VOOS A 91€!!! CORRE!" | "Lisboa → Paris (Beauvais), 91 € ida e volta" |
| "Melhor preço de sempre" | "41% abaixo do habitual em dezembro" |
| "Preço atual" | "Encontrado por um viajante a 12/10/2026" |
| "Paris" (for a BVA flight) | "Paris (Beauvais) · longe do centro" |
| "Reserva já antes que acabe" | "Estes preços desaparecem depressa." |
